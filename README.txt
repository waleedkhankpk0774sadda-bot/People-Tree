PEOPLETREE WEBSITE — FRONT-END (ENHANCED VERSION)

HOW TO USE
Open index.html in any modern browser. No build step or server needed.
To publish: upload the whole folder to any host (GitHub Pages, Netlify, Wix/hosting file manager).

FOLDER STRUCTURE
- index.html   Page structure (same layout/design as your original)
- styles.css   Original styles + a clearly marked "Modern enhancements" block at the bottom
- script.js    Menu, cart, scroll effects, newsletter
- assets/      Your original images (.png) and logo.svg

WHAT WAS ADDED (design unchanged)
- Smooth scroll-reveal animations, hero entrance animation, hover underline on menu links
- Sticky header that shrinks with a soft blur shadow; scroll-progress bar; back-to-top button
- Menu highlights the section you are viewing
- Smarter cart: quantity +/-, remove item, saved between visits, free-delivery progress bar
  (goal set by FREE_SHIP at the top of script.js), toast notifications
- Prices shown on product cards
- Lazy loading of images for faster loading
- Accessibility: skip link, keyboard focus styles, Esc closes cart/menu, reduced-motion support
- Social-share/meta tags and favicon

NOTES
- Checkout is still a placeholder; connect it to your payment/order system or WhatsApp ordering.
